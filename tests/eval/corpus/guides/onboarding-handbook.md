# 新入社員オンボーディングハンドブック

本ハンドブックは、入社初日から3か月目までに実施する手続と研修を、時系列でまとめたものである。各章は独立して参照できるが、手続の前後関係は本文中に明記する。

## 1. 入社初日

### 1.1 持ち物

入社初日は、次の書類および物品を持参する。いずれか1点でも欠けた場合、アカウント発行が翌営業日以降となる。

- 本人確認書類（顔写真付きのもの1点、または顔写真なしのもの2点）
- 年金手帳または基礎年金番号通知書
- 給与振込口座の通帳またはキャッシュカード
- 印鑑（認印可、シャチハタ不可）

### 1.2 当日の流れ

入社初日は、9時30分に受付へ集合する。午前中に人事手続とアカウント発行を行い、午後にセキュリティ研修を受講する。セキュリティ研修を修了するまで、業務システムへのアクセス権限は付与されない。

### 1.3 貸与備品の受領

初日の午後に、ノートPCおよび付属品を受領する。受領時に貸与申請書へ署名する。貸与期間および延長手続は備品貸与規程による。

## 2. 第1週

### 2.1 メンター面談

配属部署のメンターと、入社日から5営業日以内に初回面談を行う。面談記録は本人とメンターの双方が保管する。

### 2.2 必須eラーニング

第1週中に、情報セキュリティ、コンプライアンス、ハラスメント防止の3科目を受講する。3科目すべての修了をもって第1週の必須要件を満たす。未修了科目がある場合、第2週の業務割当は制限される。

## 3. 第1か月

### 3.1 目標設定

入社から30日以内に、上長と初回の目標設定面談を行う。目標は3件以上5件以下とし、各目標へ達成期限と測定方法を定める。

### 3.2 試用期間の評価

試用期間は入社日から3か月とする。試用期間中の評価は、1か月目と3か月目の2回行う。1か月目の評価は中間確認であり、この時点の評価のみを理由とする本採用の可否判断は行わない。

## 4. 第3か月

### 4.1 本採用判定

3か月目の評価をもって本採用の可否を判定する。判定結果は、試用期間満了日の10営業日前までに本人へ書面で通知する。

### 4.2 配属確定

本採用判定と同時に、正式配属先を確定する。配属先の変更を希望する場合は、判定通知の受領後5営業日以内に人事へ申し出る。

## 5. 問い合わせ

手続に関する問い合わせは、社内ポータルの人事窓口フォームから行う。電話および個人宛メールでの問い合わせは受け付けない。
