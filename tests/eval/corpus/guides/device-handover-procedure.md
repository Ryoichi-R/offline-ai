# 業務端末受け渡し手順書

本手順書は、新しく配属された社員へ業務用の端末を受け渡す際の流れを定める架空の手順書である。実在の製品名・組織名を含まない。

## 第1章 受け渡し手順

### 1.1 受け渡し日の調整

受け渡し日は、配属日の3営業日前までに配属先の担当者と調整して決める。

### 1.2 端末の初期化

前の利用者のデータが残っていないことを確認し、端末を工場出荷状態へ初期化する。

### 1.3 利用者アカウントの作成

配属先から届いた申請に基づき、利用者アカウントを作成して初回ログイン用の一時パスワードを発行する。

### 1.4 端末の貸与記録

端末の管理番号と受取者の氏名を貸与台帳へ記録する。

### 1.5 受け渡し時の説明

受け渡しの際は、紛失時の連絡先と持ち出しの手続きを受取者へ説明する。

### 1.6 受領確認

受取者から受領確認書へ署名を受け、写しを配属先へ送付する。
