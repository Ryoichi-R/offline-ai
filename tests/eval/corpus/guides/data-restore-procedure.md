# データ復元手順書

本手順書は、業務データを保管用バックアップから復元する際の流れを定める架空の手順書である。実在のシステム名・組織名を含まない。

## 第1章 事前準備

### 1.1 復元依頼の受付

復元依頼は、依頼者の所属長の承認を得た申請書でのみ受け付ける。口頭での依頼は受け付けない。

### 1.2 復元対象の特定

復元対象のデータ名と、復元したい時点の日付を申請書から作業記録へ転記する。

### 1.3 保管世代の確認

復元したい時点を含む保管世代が残っているかを保管台帳で確認する。保管期間は90日であり、90日を超えた時点には復元できない。

### 1.4 作業時間帯の調整

作業は利用者への影響を避けるため、平日の19時以降に実施する。緊急の場合に限り、情報システム責任者の許可を得て日中に実施できる。

### 1.5 作業担当者の割当

作業は2名で実施し、1名が操作、もう1名が確認を担当する。

## 第2章 復旧対応

### 2.1 復元先の準備

本番領域へ直接上書きせず、検証用の一時領域へ復元する。

### 2.2 整合性の検証

一時領域へ戻したデータについて、保管時に記録したチェックサムと照合する。照合結果が一致しない場合は、一つ前の保管世代から戻し直す。
