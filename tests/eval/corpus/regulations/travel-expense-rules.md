# 国内出張旅費規程

本規程は、当社従業員が国内へ出張する場合の旅費の取扱いを定める。海外出張は本規程の対象外とし、別途定める規程による。

## 第1条 適用範囲

本規程は、勤務地から片道50キロメートル以上離れた場所への国内出張に適用する。片道50キロメートル未満の移動は近距離移動として扱い、本規程の日当は支給しない。

## 第2条 日当

出張1日あたりの日当は、次の表のとおりとする。日当は食費および諸雑費を含むものとし、領収書の提出を要しない。

| 区分 | 役職     | 日当（1日あたり） |
| ---- | -------- | ----------------- |
| 甲   | 部長以上 | 3,500円           |
| 乙   | 課長     | 3,000円           |
| 丙   | 一般社員 | 2,500円           |

出張が半日（実働4時間以下）で終了した場合、日当は上表の半額とする。

## 第3条 宿泊費

宿泊費は実費精算とし、1泊あたりの上限額を次のとおりとする。

| 区分 | 地域                       | 宿泊費上限（1泊あたり） |
| ---- | -------------------------- | ----------------------- |
| 甲   | 東京23区・大阪市・名古屋市 | 14,000円                |
| 乙   | その他の地域               | 11,000円                |

上限額を超える宿泊が業務上やむを得ない場合は、事前に所属長の書面承認を得ること。事後承認は認めない。

## 第4条 精算期限

出張者は、出張終了日の翌日から起算して10営業日以内に精算書を提出する。期限を超過した場合、当該旅費は翌月精算へ繰り越す。
